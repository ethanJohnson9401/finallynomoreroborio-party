
# Contributing to Finally No More roboRIO

Thanks for helping us throw the most unnecessarily dramatic
retirement party in FRC history.

## Before contributing

This is an unofficial FRC parody project.

We welcome:
- Bug fixes and performance improvements
- Accessibility and responsive design improvements
- Robotics programming jokes and Easter eggs
- New interactive experiences
- Documentation and tests

Please open an issue before starting major features.

## Development requirements

- Node.js 24
- npm
- Git

## Getting started

Clone the repository:

```bash
git clone https://github.com/ethanJohnson9401/finallynomoreroborio-party.git
cd finallynomoreroborio-party
npm ci
npm run dev
```

The public website runs at http://localhost:3000.

For API development, install dependencies in `worker/`
or `admin-worker/` separately.

## Pull requests

1. Create a feature branch from `main`.
2. Keep changes focused on one issue or feature.
3. Include tests when changing API behavior.
4. Run the relevant checks before submitting.
5. Explain what changed and how you tested it.
6. Include screenshots for visual changes.

Do not directly modify production infrastructure.

## Quality standards

- Maintain the project's distinctive visual identity.
- Avoid generic landing-page components.
- Respect reduced-motion preferences.
- Support keyboard navigation and screen readers.
- Keep layouts usable on mobile.
- Avoid unnecessary dependencies.
- Never commit production secrets or user submissions.

## Moderation and privacy

Do not publish:
- Personal contact information
- Private API credentials
- Real incident reports from the production database
- Sensitive moderator information

Report security vulnerabilities privately.
